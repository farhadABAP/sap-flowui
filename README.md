# FlowUI – Modern Web Interface for SAP

FlowUI is a prototype web-based dashboard designed to modernize traditional SAP GUI transactions.  
It demonstrates how Purchase Orders (POs) can be viewed, searched, and managed through a responsive web interface, replacing the legacy SAP GUI experience.

---

## Features

- SAP-style login screen (demo credentials)
- Purchase Order dashboard with KPI statistics
- Approve / Reject workflow buttons
- Light / Dark mode toggle
- Export dashboard data to Excel
- Responsive design for desktop and mobile
- Search POs by number and view details
